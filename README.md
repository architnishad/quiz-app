# QuizApp
Java Quiz Application 

A desktop-based Quiz Application developed using Java Swing. The application provides an interactive quiz experience with a login screen, rules section, multiple-choice questions, timer, and final score display.

🚀 Features

- User login with name validation
- Quiz rules and instructions
- Multiple-choice questions
- Countdown timer for each question
- Next and Submit functionality
- Automatic score calculation
- Final score/result screen
- User-friendly graphical interface
- Custom icons and images using Java Swing

🛠️ Technologies Used

- Java
- Java Swing
- AWT
- OOP Concepts
- Event Handling
- IntelliJ IDE

▶️ How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Make sure Java JDK is installed.
4. Run "Login.java".
5. Enter your name and start the quiz.
